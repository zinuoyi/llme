# 2. Choices of model and inference platform

Date: 2025-04-14

## Status

Accepted

## Context

We need to choose a LLM that can run on our laptops and be used for test pipeline.

We also need a inference platform to deploy LLMs locally, inference faster, and cost less GPU Mem.

#### Principles of Choosing LLMs:

1. GPU Mem Limitation
2. Context Length
3. As latest as possible
4. Textual Model

#### Principles of Choosing Inference Platform

1. Inference Speed, GPU Mem costs
2. Support for LLMs
3. Ease of Use
